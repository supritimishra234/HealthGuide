 HealthGuide

HealthGuide is a simple web application that provides health information based on the symptoms entered by the user. I built this project to understand how a frontend can work with a PHP backend and a MySQL database.

 What it does

- Allows users to search for symptoms
- Shows related health information
- Uses a MySQL database to store the information
- Connects the frontend to the database through PHP
- Has a simple and responsive interface

Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
